# Task 1: Responsive Webpage Development

## Description
A simple responsive webpage built using HTML, CSS, and JavaScript. The design adapts seamlessly across desktop, tablet, and mobile devices.

## Features
- Fully responsive layout
- Navigation menu
- Basic styling with CSS
- Works on multiple screen sizes

## How to Run
1. Clone the repository or copy the folder.
2. Open `index.html` in a browser.
3. Resize the browser window to see the responsiveness.
